# 电容

## 电容是什么

电容（Capacitor） 是一种能够存储电荷的被动电子元件，由两个相互靠近的导体（极板）和中间的绝缘介质构成。其核心功能是储存电能并在电路中实现电荷的充放电。电容器所带的电荷量Q与电容器两极板间的电势差U的比值叫做电容器的电容，用字母C表示，单位是法拉（F）。

电容公式：C = Q / U

1F = 10^6^μF = 10^12^pF

## 电容的结构与工作原理

### 物理结构

- 极板（Plate）：两个导电材料（如金属箔、金属化薄膜）构成。

- 介质（Dielectric）：绝缘材料（如陶瓷、电解液、塑料薄膜），决定电容性能。

- 引线（Lead）：连接极板与电路的导线。

### 工作原理

充电：电容接入电源时，正极吸引电子，负极失去电子，两极板间形成电场，存储电荷。

放电：断开电源后，电荷通过外部电路释放，直至两极板电势差为零。

## Q&A

### Q1：电容是怎么“存电”的？

电容通过**绝缘层把正负电荷分开并困在两块极板上**来“存电”。
加电压时，一边极板电荷变多，另一边变少；
由于中间是绝缘的，电荷不能直接流过去，只能**堆在极板表面**，形成并维持电场。
因此电压被保持住，本质上**存的是电场能量，而不是电子本身**。

### Q2：什么因素决定“电容 C 的大小”？

- 极板面积

	- 面积大 → 能“堆”更多电荷

	- 面积小 → 能存的少

- 极板之间的距离

	- 距离近 → 电场强 → 电容大
	- 距离远 → 电容小

- 中间的材料（介质）

	- 不同绝缘材料，能力不同
	- 用“介电常数”描述
