# OLED入门

## 什么是OLED

OLED（Organic Light Emitting Diode，有机发光二极管）是一种基于有机半导体材料的自发光显示技术。在电场驱动下，电子与空穴分别从阴极和阳极注入，经传输层迁移后在发光层复合并产生光子。与LCD不同，OLED无需背光源，每个子像素可独立发光，在关闭时可实现接近纯黑的显示效果，因此具有高对比度、快速响应和薄型化等优势。

## OLED结构

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202142610593.jpeg)

- **阴极（Cathode）**：注入电子，阴极通常是金属（如铝、镁银合金）。
- **电子注入层（EIL）**：优化电子从阴极向有机层的注入效率。
- **电子传输层（ETL）**：将电子传输至发光层。
- **有机发光层（EML, Emissive Layer）**：电子与空穴在此复合，激发有机物发出红、绿或蓝色光。
- **空穴传输层（HTL）**：将空穴传输至发光层。
- **空穴注入层（HIL）**：优化空穴从阳极向有机层的注入效率。
- **阳极（Anode）**：注入空穴，通常为透明材料（如ITO）。
- **基板（Substrate）**：提供物理支撑。AMOLED中通常在基板上先构建TFT驱动电路，再在其上方形成阳极层，与有机发光层相连。

## OLED发光原理

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202201325636.png)

在OLED器件上施加适当电压后，阳极向发光层注入空穴，阴极向发光层注入电子，电子与空穴在电场作用下进入器件并形成电流，在发光层中相遇并复合形成激子。激子通过扩散在发光层中迁移，并通过能量转移机制将能量传递给掺杂发光分子，使其电子由基态跃迁至激发态；由于激发态不稳定，电子会返回基态并以光子的形式释放能量，从而产生可见光，这就是OLED的发光过程。

OLED像素的发光亮度与流过该像素的电流大小成正比，因此通常采用电流源方式进行驱动控制。同一器件中，电流越大，复合产生的激子数量越多，发光强度也越高。

OLED的发光颜色由发光层中有机发光材料的类型决定。有机发光材料具有特定的能级结构，在吸收电子与空穴复合所释放的能量后，通过能级跃迁释放特定波长的光子，人眼据此感知为不同颜色。通过在同一显示面板中配置不同发光波长的有机发光材料（如红、绿、蓝发光层），即可实现彩色显示。

## OLED分类

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202163013289.png)

### **按驱动方式分类**

#### **PMOLED（被动矩阵 OLED）**

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202164329558.png)

- 采用**行列扫描驱动**结构，由条状阳极与条状阴极交叉形成像素点，本身**无TFT背板**
- 通过逐行逐列扫描点亮像素，每个像素工作在**短脉冲驱动模式**
- 像素亮度由扫描期间的驱动电流决定，受**占空比限制**

**特点：**

- 结构简单、制造成本较低
- 不需要像素级晶体管驱动
- 驱动电流较大、效率随分辨率升高而下降
- 难以实现高分辨率和大尺寸
- 多采用外接驱动IC（如COG / TAB）

#### **AMOLED（主动矩阵 OLED）**

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202164354657.png)

- 采用**TFT有源矩阵背板**，每个像素由多个TFT + 存储电容构成像素电路
- 每个像素可被**独立选通与电流控制**
- 像素可持续发光，不依赖行列扫描占空比

**特点：**

- 像素独立驱动，支持高分辨率、高刷新率
- 发光电流由像素电路精确控制 → 亮度一致性好
- 功耗更优（按像素发光，不需整行扫描大电流）
- 易于实现大尺寸与高PPI
- 驱动电路集成在面板内，模组集成度高

> 背板 = 基板 + TFT + 像素电路 + 互连结构

### 按发光结构分类

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202165853588.png)

AMOLED拥有**底发光**与**顶发光**两种结构。顶发光结构中，光线不会受到驱动电路的遮挡，相比底发光结构拥有更高的开口率，从而在高解析度的应用中具有更大的优势，因此逐渐成为了AMOLED的主流。

> 开口率越高，像素中可发光面积越大，在相同电流下亮度更高、功耗更低；同时在高PPI条件下像素尺寸更小、驱动电路占比更高，提高开口率有助于保证足够的发光面积，从而支持高PPI显示。

### 按色彩控制分类

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202202445561.png)

### 按薄膜晶体管 （TFT）背板材料分类

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20260202214049087.png)

a-Si TFT 由于迁移率过低且在高温或长时间静态显示下容易产生阈值漂移，难以满足 OLED 对驱动电流和可靠性的核心要求；纯 IGZO TFT 稳定性高、低泄漏，但迁移率仍不足以独立支撑高亮度、高刷新率 OLED 的驱动需求，因此业界普遍采用性能更强的 LTPS 或混合型 LTPO（LTPS + IGZO）方案，以兼顾高驱动能力与低功耗优势。

#### **低温多晶硅（LTPS,Low Temperature Poly-Silicon）**

- **优点**：
	- 电子迁移率高（50~200 cm²/V·s），适合高分辨率显示
	- 可支持NMOS/PMOS/CMOS结构
	- 功耗较低
	- 集成度高，可靠性好
	- 适用于中小尺寸OLED面板
- **缺点**：
	- 均一性较差，易出现Mura（显示不均）
	- 制程复杂，Mask数量多（7~11层）
	- 价格较高
	- 良率相对较低

> LTPS的“不均”主要是出厂时的静态差异，工作中也会有小幅Vth漂移，但可通过补偿校正；a-Si的“漂移”是在工作中持续加重的动态恶化，难以有效抑制，因此OLED背板弃用a-Si而选择LTPS。

#### **低温多晶氧化物（LTPO,Low Temperature Poly-Oxide）**

- **优点**：
	- 结合LTPS高迁移率与氧化物TFT低功耗特性
	- 漏电流极小，存储电容保持时间长
	- 支持极低刷新率（如1Hz），无明显影像残留
	- 在持续低刷新率下比LTPS节省5~15%功耗
- **缺点**：
	- 叠加LTPS与Oxide工艺，Mask层数多（12-15层），良率挑战大 
	- 低频闪烁（Flicker）抑制难，需要算法补偿
	- 每个像素内需要容纳更多的晶体管，高 PPI 下挤压发光面积，增加功耗压力

## OLED与LCD的核心差异

OLED的优势的本质是“自发光”对LCD“背光+液晶”结构的颠覆，具体差异如下表：

| **特性** | **LCD**                              | **OLED**                       |
| -------- | ------------------------------------ | ------------------------------ |
| 驱动信号 | 电压控制                             | 电流控制                       |
| 物理基础 | 背光模组发光，液晶分子旋转改变透光率 | 有机材料自发光，像素独立控制   |
| 驱动电路 | 1T2C                                 | 7T1C                           |
| 核心参数 | 电压调节液晶偏转角度                 | 电流决定发光强度               |
| 黑色表现 | 灰黑色(背光无法完全关闭)             | 纯黑色(像素0电流关闭)          |
| 响应速度 | 1-5ms(液晶偏转延迟)                  | 0.001ms(电致发光瞬间响应)      |
| 功耗     | 背光全开，功耗固定                   | 像素按需发光，深色内容省电30%+ |
| 可视角度 | 视角越大，色彩/亮度衰减越明显        | 接近180°全视角，色彩无衰减     |
| 柔性特性 | 刚性结构，无法弯曲                   | 可实现折叠、卷曲（柔性基板）   |
| 烧屏风险 | 风险小                               | 静态界面长时间显示导致残影     |
| 寿命限制 | 背光衰减                             | 有机材料老化                   |
| 制造难度 | 成熟工艺，难度低                     | 制造工艺复杂，难度高           |

> **可视角度**：OLED 像素直接发光，侧视时亮度与色彩几乎无衰减；LCD 需透过液晶层与偏光片，侧视时亮度与色彩显著下降。
>
> **柔性特征**：OLED 采用薄膜塑料基板与封装，可实现弯曲折叠；LCD 由液晶层、偏光片及背光模组组成，需保持平整厚重，故屏幕刚性强，无法柔性化。
