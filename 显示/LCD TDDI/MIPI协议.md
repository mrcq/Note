# MIPI

### **MIPI的概念与特点**

#### **MIPI的概念**

- **全称**：Mobile Industry Processor Interface（移动产业处理器接口）
- **定位**：由 **MIPI联盟** 制定的**开放性标准体系**，专为移动设备（手机/平板/车载/IoT）内**芯片间互联**设计。
- **目标**：解决传统并行接口的**高功耗、布线复杂、EMI干扰**问题，提供**高速、低功耗、模块化**的通信方案。

#### **MIPI的特点**

| **特点**         | **说明**                                                     |
| :--------------- | :----------------------------------------------------------- |
| **分层架构**     | 应用层、协议层、物理层解耦设计<br />\- **应用层**：处理数据语义（如图像格式）<br/>\- **协议层**：定义数据包结构（如CSI-2的Packet Based传输）<br/>\- **物理层**：处理电气信号（如D-PHY或C-PHY） |
| **低功耗优化**   | 支持动态切换高速（HS）与超低功耗（LP/ULPS）模式              |
| **高速串行传输** | 通过差分信号（如LVDS）减少信号线数量，提升抗干扰性           |
| **模块化扩展**   | 按场景定制协议，如多媒体（DSI/CSI）、存储（UniPro）、控制（I3C）等 |
