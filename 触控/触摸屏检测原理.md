# 触摸屏检测原理

当手指触摸在屏幕上时，由于人体电场，手指和触摸屏表面形成一个耦合电容，此电容会影响到屏幕手指触控位置寄生电容的变化（等效），通过侦测这个电容的变化（等效转化成电压的变化）来定位坐标，将坐标X/Y上报给系统

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803204729638.png)

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803204808096.png)

## 互容

当手指触摸到电容屏时，影响触摸点附近两个电极之间的耦合，从而改变了这两个电极之间的电容量，检测电容大小时，横向的电极依次发出激励信号（Tx），纵向的所有电极同时接收信号(Rx)，这样得到所有横向和纵向电极交汇点的电容值大小，即整个触摸屏的二维平面电容的大小。
检测Tx与Rx交叉节点的**互电容**（Cm）。手指（接地导体）靠近时，**部分电场被分流至地**，导致Tx-Rx间的有效耦合电容减小（△C↓）。

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803205050143.png)

### 互容-扫描方式
互容主要侦测的是Tx及Rx交汇节点的电容差异，其驱动一般是Tx一条一条进行驱动（未驱动的其他Tx接到GND），Rx同时接收，共获得二维平面Tx * Rx节点个数据，此时通过手指触摸节点电容变化确认手指的位置。

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803205451542.png)

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803205521774.png)

## 自容

检测单个电极与地之间的电容变化，自打自收。手指触摸时形成耦合电容（Cf），导致总电容增加（C = Cp + Cf），通过测量电容增量定位坐标。

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803205643511.png)

### 自容-传统自容

- 如图一，三角形自电容，通过侦测L/R上面电容变化的大小确认手指落在哪条L/R上，确认X的坐标，再通过L/R感应量抬起的比例判断Y的位置。(通过测量相邻电极的电容变化梯度计算Y坐标)
- 如图二，横向与纵向走线形式自电容，通过自身的自打自收获取到X&Y两组一维数据，通过这两
	组数据确定手指坐标。
- 优点：结构相对比较简单，数据处理较少，Floating效果较好。
- 缺点：不能实现多指操作，多指有鬼点。

> 在电容触控技术中，“Floating效果较好”特指**自电容方案对悬浮触控（Floating Touch）的检测能力更强**，即手指在屏幕上方悬空时（未接触屏幕），系统仍能准确感知手指位置。
>
> **自电容方案的优势**
>
> - 信号强度高：自电容传感器（单根X或Y走线）的电极面积较大，产生的电场强度更高，可穿透空气检测悬空手指（互电容因电极交叉点面积小，信号弱，无法有效检测悬空状态）。
> - 检测距离远：自电容可感知屏幕上方20mm内的手指，而互电容通常仅支持接触式触控。

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803210116356.png)

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803210135758.png)

- 传统外挂式自容按Channel检测，两指以上会有鬼点问题。

	> 传统自容的鬼点源于**一维数据**（X/Y轴独立扫描），无法区分真实触点的组合（如图中两指必然在X/Y轴各产生两个峰值）。
	>
	> TDDI方案因检测**二维平面数据**（每个RX独立），可规避此问题。

	![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803210226656.png)

### 自容-TDDI

- 将显示的VCOM进行切割成很多的小块，显示扫描的时候叫做VCOM ,TP扫描的时候叫做RX。
- 因为是整个平面进行切割，TP扫描会侦测每个小块对地电容的变化量，即会获得一个平面的感应量数据，此时可以通过数据的变化确认手指触摸的位置，其可以支持多指触控。

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250803210438658.png)

## 区别

- 互容电容减小：因手指作为接地导体分流TX-RX间的电场，削弱有效耦合，属于 “减法效应”。

- 自容电容增大：因手指与RX电极形成并联到地的附加电容，属于 “加法效应”。

| **特性**       | **自容式 (Self-Cap)**                                        | **互容式 (Mutual-Cap)**                                      |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **检测对象**   | RX电极对地电容                                               | TX-RX交叉点耦合电容                                          |
| **触摸后变化** | 电容 **增大**（并联增加新路径）                              | 电容 **减小**（电场被手指分流）                              |
| **物理本质**   | 新增手指-地电容（Cf）叠加                                    | TX-RX间有效耦合电场减弱                                      |
| **抗干扰性**   | ✅ **抗耦合噪声强** （如显示噪声） ➤ *成因：对地检测时耦合噪声均匀影响所有电极，易被差分抵消* | ✅ **抗共模噪声强** （电源/EMI） ➤ *成因：差分检测Tx-Rx信号可抑制共模干扰* |
|                | ❌ **易受共模噪声** （电源/EMI） ➤ *成因：电源波动直接污染接地参考点* | ❌ **易受耦合噪声** （如显示刷新干扰） ➤ *成因：噪声直接侵入Tx-Rx间耦合路径* |
| **典型应用**   | TDDI LCD（结构简单+抗显示噪声）                              | 外挂触控/主动笔（高精度多点）                                |
| **防水**       | ❌ **水/手同向干扰**： 水滴（悬浮导体）与手指（接地）均增大对地电容 → 仅靠幅度难区分 | ✅ **水/手反向变化**： - 手指（接地）：**分流电场 → 互容↓** - 水滴（悬浮）：**增强局部耦合 → 互容↑** → 算法可锁定↓信号过滤水滴 |

> - 自容易受**电源噪声/环境电磁干扰**（因直接对地检测），互容易受**TX-RX间耦合噪声**（如显示屏刷新干扰）。
> - 自容对耦合噪声敏感，互容对共模噪声敏感。

## 电容检测原理

### 为什么选择“电容”作为检测对象？

电容的本质是导体存储电荷的能力，它的变化可以直观反映人体（导体）的接近或接触。而其他物理量（如电阻、电感）难以直接对应人体的电场特性：

1. 人体自带电场特性：人体相当于一个接地的导体，触摸屏幕时，手指会与屏幕电极形成耦合电容（Cf），这一变化是电容式触控的物理基础。
2. 无需机械压力：电容检测不依赖压力形变（如电阻屏），仅需轻微接触或悬空即可响应，体验更自然。
3. 结构适配性强：电容传感器可直接集成在透明ITO导电层中，不影响屏幕透光性，适合嵌入玻璃或塑料面板。

### 电容变化如何被检测到？

电容本身无法直接测量，需通过电路将其转化为可量测的电信号（如频率、电压、时间差）。常用检测技术有三种：

|   **检测方法**   |         原理         | 适用模式  |         优势         |
| :--------------: | :------------------: | :-------: | :------------------: |
| **驰张振荡电路** | 测量电容充电时间变化 |   自容    |   电路简单，成本低   |
| **电荷转移电路** |  统计充放电次数差异  |   自容    |   抗干扰强，功耗低   |
|   **CDC电路**    |  电容→电压→数字信号  | 互容/自容 | 精度高，支持多点触控 |

> 电荷-电压转换（CDC）方案因**高信噪比**和**数字化集成优势**，成为主流互容检测方案

### **为何不用其他器件（如电阻）？**

1. 电阻式触摸屏：
	- 依赖压力形变使上下ITO层接触，需用力按压，易磨损且不支持多点触控。
2. 电容式的优势：
	- 无接触磨损，寿命长。
	- 支持悬浮触控（Floating Touch）。
	- 天然适配人体电场特性。
