# 短路测试

## 测试目的

- TP通道之间是否存在短路（包括对地短路，行之间短路，列之间对路）
- 测量范围0 - 1MΩ
- 可计算发生短路的具体位置及对应阻抗
- 卡控阈值设定方案：按照500kΩ进行卡控 

## 测试原理

### 符号定义及公式

| **符号** | **含义**                              |
| -------- | ------------------------------------- |
| Rsen     | sensor通道的电阻                      |
| Csen     | sensor通道等效电容                    |
| Rsw      | RX MUX导通电阻                        |
| Rs       | 内部串联电阻                          |
| Rdrv     | 驱动电压源内阻                        |
| Vpwr     | 电源电压, 0 或 VDDA                   |
| Vdrv     | 驱动电压, 本设计中使VSTIM作为驱动电压 |
| VO       | 输出到ADC，转化为数字信号进行处理     |
| Rshort   | sensor到GND/VDD的短路电阻             |

> **VO是检测点模拟电压 → ADC将其量化（采样+数字转换）→ 输出Rawdata（数值与VO成正比）**

### RX对GND/VDD短路

#### 公式


```math

```

### 总结

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250807112119033.png)

| **状态** | **R_short物理意义** | **数值表现**       | **测试现象**           |
| :------- | :------------------ | :----------------- | :--------------------- |
| **短路** | 短路点实际电阻      | **极小** (<<500kΩ) | 电流抄近路，电压被拉低 |
| **正常** | 无穷大（绝缘）      | **极大** (>500kΩ)  | 电流走正道，电压无异常 |

> 9911C的Radj = 108kΩ ；饱和值=无短路时的short rawdata；

## 测试流程

### RX对GND/VDD短路

- 切换到Short Detect模式
- 设定为对地/电源短路检测模式（形成等效电路）
- 扫描一屏Raw Data
- 上位机获取Raw Data并进行根据对地短路公式计算每个sensor的𝑅_𝑠ℎ𝑜𝑟𝑡 ，对于𝑅_𝑠ℎ𝑜𝑟𝑡小于临界值（R_TH）的点，即认为该点Short
- 报告发生短路的行列号及短路电阻值。

### RX与RX之间短路

- 切换到Short Detect模式
- 设定为Rx/Rx短路检测模式（形成等效电路）
- 根据芯片扫描方式，依次扫描相邻列/行的Raw Data
- 上位机获取Raw Data并进行根据Rx/Rx短路公式计算𝑅_𝑠ℎ𝑜𝑟𝑡，对于𝑅_𝑠ℎ𝑜𝑟𝑡小于临界值（R_TH）的点，即认为该点Short
- 报告发生短路的行列号及短路电阻值。

## 不良分析

- bonding是否正常？

	3D X-Ray 虚拟切片分析是否焊盘焊锡溢出造成与旁边GND短路；解焊植球后单IC测试通道是否正常

- 功耗是否异常？

	功耗异常说明IC内部可能有热点

	- RX MUX内部电路受损，会导致信号路径异常，可能引发短路问题（如信号通道间意外连接）
	- RX电路内部创建了低阻抗路径（如晶体管击穿），使电源和地线间形成短路点，引发异常电流和short测试失败 

- IC SWAP可以判断异常是否由IC不良导致，如和IC有关则InGaAs分析，看是否有异常热点

- 可能的制造工艺问题：通过OBIRCH、OM、SEM等手段，查看RX metal是否存在异常bridge
