# 开路测试

## 测试目的

- TP通道是否存在开路
- 测量范围1MΩ~∞
- 卡控阈值设定方案：按照当前扫描参数配置下，Rx通道开路的真实数据进行卡控

## 测试原理

- 对于开路的节点，IC未接到sensor上，所以IC检测的loading明显小于接到sensor上的节点
- 利用开路状态下的rawdata值和panel状态下rawdata值的差异进行开路卡控

## 功能实现

- 调整补偿电容Cneg到合适位置
- 使用开路环境（COB）运行开路测试，记录此配置下开路状态的Rawdata
- 在panel上运行开路测试，记录此配置下面板的Rawdata值
- 取开路状态下rawdata值作为卡控阈值设定依据，若小于卡控阈值则判定为fail

## 测试流程

- 通过小批量屏测试实验获取临界值（ TH_OPEN ）
- 切换到Open Detect模式
- 扫描一屏Raw Data
- 上位机获取Raw Data并进行分析，对于Raw Data小于临界值（TH_OPEN）的点，即认为该点Open。

![](https://cdn.jsdelivr.net/gh/mrcq/Image@main/20250804101305397.png)

- 上位机动作

	- Set open short mode to open
	- Set work mode from config to open short detect
	- Get open short data (Rawdata)
	- 判断每一个 rx，如果小于阈值，则认为 open

- FW动作

	- 设置 open 模式下的 Cneg
	- 扫一帧 Rawdata
	- 恢复原来 Cneg
	- 将 Rawdata 传输给 host

	> 注意：扫描一帧 Rawdata 过程中，Cneg 会对 Rawdata 的大小产生影响。如果 Cneg 设置过大，会导致 Rawdata 偏小，容易被误判为 Open。因此 Open 模式下的 Cneg 最好单独设定。

## 不良分析

- 显示效果是否正常？重载图？

	如果真的开路了，开路点Vcom电极浮空， 液晶分子异常偏转，示重载图局部小方格。

- bonding是否正常？

	3D X-Ray 虚拟切片分析是否虚焊；解焊植球后单IC测试通道是否正常

- sleep和deep sleep功耗是否异常？

	功耗异常说明IC内部有热点

- 开路位置触碰是否有diff？

	没有diff说明确实RX断开，没有感应量

- IC SWAP可以判断异常是否由IC不良导致，如和IC有关则InGaAs分析，看是否有异常热点

- 异常数据是否由关联（比如同为一个AFE），如为同一个AFE，可断开Loading观察数据变化，观察不良节点AFE的VCA_OUT输出波形

	> AFE为前端控制模块于连接 Touch Rx 采集电容数据的单元，当此受损造成输出异常。
	>
	> **VCA_OUT 是 AFE 的输出信号**，它是经过压控放大器（VCA）动态调整后的触摸信号，为后续电路（如 ADC）提供稳定输入。
