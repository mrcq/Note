# 触控名词解释

### **AFE (Analog Front End，模拟前端)**

- 此处是指用于连接Touch Rx采集电容数据的单元。

### **ADC (模数转换器)**

- **量化转换**：将AFE输出的模拟电压信号转换为数字值
- **输出结果**：生成表征电压大小的数字量（即 **Rawdata**）
- **关键参数**：分辨率（如12-bit）、采样速率（决定扫描帧率）

> **分辨率**告诉你“细节有多丰富”（数字值的精度）。
> **采样速率**告诉你“采集的速度有多快”（数据刷新频率）。
> ADC 是触控报点率的“起跑线”，它的速度直接限制每帧采集效率，决定系统是否能支持高频响应（如120Hz/180Hz）等高性能触控需求。

### **RX (接收通道)**

- 触控屏上**横纵矩阵排列的金属电极**（通常为ITO走线）
- 感应触摸导致的**电容变化**（ΔC）
- 将电容信号转化为**电流信号**输入AFE

### **DUMMY RX (虚拟接收通道)**

- 插入真实RX之间的**假想电极**（无传感功能）
- **全驱降Loading**：
	1. 施加与驱动端（TX）**同相位/同幅值**的电压
	2. 消除相邻RX间电势差 → **抑制互容耦合干扰**
	3. 降低传感器网络等效容抗 → **提升信噪比**

### **TP MUX**

- TP MUX是指几个通道复用一个AFE。
- 9911C AFE：9911C TP MUX为1:8，9911C是行扫，行\*列为32\*18，扫8轮，32/8=4 每次扫4行，4\*18=72 总共有72个AFE。
- 9916 AFE：9916 TP MUX为1:9，9916是列扫，行\*列为32\*18，扫9轮，18/9=2 每次扫2列，2\*32=64 总共有64个AFE。
- 9916C AFE：9916C TP MUX为1:9，9916C是列扫，行\*列为32\*18，扫9轮，18/9=2 每次扫2列，2\*32=64 总共有64个AFE。
- 9922C AFE：9922C TP MUX为1:5，9922C是列扫，行\*列为36\*18，扫5轮，18/5=3.6->4 每次扫4列，4\*36=144 总共有144个AFE。

### **RX SEL（接收通道选择寄存器）**

- **作用**：控制 RX MUX，将指定的 RX 通道连接到 AFE，支持通道复用
- **原理**：AFE 通道数量有限，但 RX 总通道数量很多，`RX_SEL` 控制内部模拟开关阵列，使选定的 RX 信号接入当前的 AFE 输入端口，实现**时分复用**

### **MBIST (存储器内建自测试)**

*—— 硬件直连SRAM的测试*

- **读写路径**：数字MBIST模块 → **直接访问 SRAM**
- **触发时机**：FW下载前自动执行（**无需FW**）
- **覆盖范围**：**100% SRAM物理单元**

### **MCU SRAM测试**

*—— 通过总线访问SRAM的测试*

- **读写路径**：MCU → **AHB/AXI系统总线** → SRAM
- **触发条件**：需加载**微型固件**（如：<10KB，<font color="#FF0000">**压缩至足够小**</font>）
- **测试流程**：
	<font color="#FF0000">1. 使用Var RAM作Cache区 → 遍历Data RAM</font>
	<font color="#FF0000">2. 使用Data RAM作Cache区 → 遍历Var RAM及其他区域</font>

> **本质**：**通过分阶段互斥测试覆盖整个SRAM**

### **SRAM（ICNL9916）**

*—— 基于物理地址划分的独立存储区块*

|   分区名称   | 基地址  |    大小    |
| :----------: | :-----: | :--------: |
| **PRG1_RAM** | 0x00000 |    32K     |
| **PRG3_RAM** | 0x08000 |    32K     |
| **PRG5_RAM** | 0x10000 |    16K     |
| **VAR1_RAM** | 0x14000 |    16K     |
| **DAT1_RAM** | 0x18000 |    16K     |
| **DAT2_RAM** | 0x1C000 |    16K     |
| **RAW1_RAM** | 0x20000 | 1664 Bytes |
| **RAW2_RAM** | 0x21000 | 1664 Bytes |
| **CNEG_RAM** | 0x22000 | 832 Bytes  |
| **CMIR_RAM** | 0x23000 | 832 Bytes  |
| **ACC1_RAM** | 0x24000 | 128 Bytes  |
| **ACC2_RAM** | 0x24800 | 128 Bytes  |

### **TPS**

- TPS是指Touch工作的时间片。
- 其它称呼包括”坑”，Touch Term等。
