# 触控名词解释

### **AFE (模拟前端)**

- **信号采集**：接收来自RX通道的微弱电容感应电流
- **信号调理**：
	- 放大（通过可编程增益放大器PGA）
	- 滤波（抑制显示噪声与高频干扰）
	- 解调（分离有用信号与载波）
- **信号传递**：将处理后的模拟电压输出至ADC

### **ADC (模数转换器)**

- **量化转换**：将AFE输出的模拟电压信号转换为数字值
- **输出结果**：生成表征电压大小的数字量（即 **Rawdata**）
- **关键参数**：分辨率（如12-bit）、采样速率（决定扫描帧率）

> **分辨率**告诉你“细节有多丰富”（数字值的精度）。
> **采样速率**告诉你“采集的速度有多快”（数据刷新频率）。
> ADC 是触控报点率的“起跑线”，它的速度直接限制每帧采集效率，决定系统是否能支持高频响应（如120Hz/180Hz）等高性能触控需求。

### **RX (接收通道)**

- 触控屏上**横纵矩阵排列的金属电极**（通常为ITO走线）
- 感应触摸导致的**电容变化**（ΔC）
- 将电容信号转化为**电流信号**输入AFE

### **DUMMY RX (虚拟接收通道)**

- 插入真实RX之间的**假想电极**（无传感功能）
- **全驱降Loading**：
	1. 施加与驱动端（TX）**同相位/同幅值**的电压
	2. 消除相邻RX间电势差 → **抑制互容耦合干扰**
	3. 降低传感器网络等效容抗 → **提升信噪比**

### **RX MUX (接收通道多路复用器)**

- 由晶体管构成的**物理开关阵列**
- **通道扩展**：将有限的AFE输入端口分时复用至大量RX通道
- **信号路由**：根据RX_SEL指令导通目标RX至AFE

### **RX SEL（接收通道选择寄存器）**

- **作用**：控制 RX MUX，将指定的 RX 通道连接到 AFE，支持通道复用
- **原理**：AFE 通道数量有限，但 RX 总通道数量很多，`RX_SEL` 控制内部模拟开关阵列，使选定的 RX 信号接入当前的 AFE 输入端口，实现**时分复用**
