# vim

Vim 的配置文件分为两种，一种是全局配置文件（/etc/vim/vimrc），一种是用户配置文件（/home/<Username>/.vimrc）。全局配置文件会对系统内所有用户生效，包括 root 用户。而用户配置文件只对单个用户有效

## 配置

```shell
"语法高亮"
syntax on
"显示行号"
set number
"显示当前光标位置"
set ruler
"使用vim而非vi"
set nocp
"c/c++自动缩进"
set cindent
"缩进4个空格"
set ts=4
"不用交换文件"
set noswapfile
"文本宽度80列自动换行"
au FileType c,cpp,python,vim set textwidth=80
"竖线警示"
"set colorcolumn=81"
"高亮当前行"
set cursorline
"鼠标滚轮"
if has("autocmd")
  au BufReadPost * if line("'\"") > 1 && line("'\"") <= line("$") | exe "normal! g'\"" | endif
  set mouse=a
endif
```

## 快捷键

| 类别         | 快捷键           | 功能说明                            | 使用场景与技巧                             |
| :----------- | :--------------- | :---------------------------------- | :----------------------------------------- |
| **模式切换** | `i`/ `a`         | 在光标**前/后**进入插入模式         | 最常用的进入编辑方式                       |
|              | `I`/ `A`         | 在**行首/行尾**进入插入模式         | 快速修进行头或行尾                         |
|              | `o`/ `O`         | 在**当前行下方/上方**新建空行并插入 | 快速开始新一行                             |
|              | `Esc`或 `Ctrl+[` | **返回普通模式**                    | 执行任何命令的前提                         |
| **光标移动** | `h``j``k``l`     | **左、下、上、右**移动光标          | 必须形成肌肉记忆的基础移动                 |
|              | `w`/ `b`         | 移动到**下一个/上一个单词**的词首   | 在代码或文字间快速跳跃                     |
|              | `0`/ `^`/ `$`    | 移动到**行首/行首非空字符/行尾**    | `^`和 `0`的区别很重要                      |
|              | `gg`/ `G`        | 跳到**文件第一行/最后一行**         | 快速定位文件首尾                           |
|              | `:n`或 `nG`      | 跳到**第n行**（如 `:10`或 `10G`）   | 精准定位到特定行                           |
| **编辑操作** | `dd`/ `yy`       | **删除（剪切）/复制**当前行         | 最基础的行操作                             |
|              | `p`/ `P`         | **粘贴**到光标后/前                 | 粘贴剪切或复制的内容                       |
|              | `u`/ `Ctrl + r`  | **撤销/重做**上一步操作             | 修错时的“后悔药”                           |
|              | `x`              | **删除**当前光标下的字符            | 删除单个字符                               |
| **搜索替换** | `/keyword`       | **向下搜索**指定字符串              | 搜索后按 `n`下一个，`N`上一个              |
|              | `?keyword`       | **向上搜索**指定字符串              | 与 `/`方向相反                             |
|              | `:%s/old/new/g`  | **全局替换**（将所有old换为new）    | 修改代码或文本时威力巨大                   |
|              | `*`              | **高亮并快速跳转**到下一个相同单词  | 查找光标所在单词的下一个出现位置，非常高效 |
| **文件操作** | `:w`             | **保存**文件                        | 经常保存是好习惯                           |
|              | `:wq`或 `ZZ`     | **保存并退出**                      | 最常用的退出方式                           |
|              | `:q!`            | **强制退出**（不保存修改）          | 修改出错想重新来时使用                     |
