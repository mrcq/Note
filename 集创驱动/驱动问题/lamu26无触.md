# lamu26无触

## 现象

- 测试反馈无触手法：灭屏，插入数据线，亮屏滑动有几秒钟无触，然后自动恢复
- FAE确认现象：
	1. 无触时显示正常，触控扫描正常，无跳频——>确认异常时TP扫描状态
	2. 从LP或FS切到normal都会无触——>确认异常时触控模式切换流程
	3. 连接PC 20亮屏测试20次无复现无触，连接手机电源7/10次复现无触——>确认异常复现手法
	4. 灭屏插usb复现无触，插usb灭屏后拔usb无法复现无触——>确认异常复现手法
	5. wifi adb debug，无触时无中断计数、input event事件
	6. 导入关闭手势、跳频、palm的固件，仍无触
