# 驱动初始化流程

```flow
graph LR;
st=>start: cts_driver_init

op_comm=>operation: 根据配置注册spi或iic驱动
op_probe=>operation: 驱动检测（probe）
op_panel=>operation: panel

cond_panel=>condition: 根据配置获取面板类型
cond=>condition: 111

sub_panel=>subroutine: 通过解析内核全局变量saved_command_line(cat /proc/cmdline)来获取当前面板类型

e=>end: 驱动初始化结束
 
st->op_comm->op_probe->cond_panel
cond_panel(no)->cond
cond_panel(yes)->sub_panel->cond
```
