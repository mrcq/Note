# 设备树

## 编译设备树

在内核根目录下，运行下面指令会根据 `arch/arm/boot/dts/`（针对ARM架构）或 `arch/arm64/boot/dts/`（针对ARM64架构）目录下的 Makefile 配置，编译所有已启用的设备树源文件。

```shell
make dtbs
```

## **设备树的存放与输出路径**

设备树文件（包括 `.dts`源文件、编译后生成的 `.dtb`二进制文件以及被包含的 `.dtsi`头文件）通常都位于 Linux 内核源码的 `arch/arm/boot/dts/`(32位系统) 或 `arch/arm64/boot/dts/`(64位系统) 目录及其子目录下。

# 反编译

dtc -I dtb -O dts -o <输出文件名>.dts <输入文件名>.dtb

## 设备树子节点格式

```
[label:] node-name[@unit-address] {

[properties definitions]

[child nodes]

};
```

## 设备树常见参数

| 参数名称                             | 功能说明                                                     | 示例与取值                                                   |
| :----------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **`compatible`**                     | **驱动匹配的关键**，值为字符串列表，内核据此为设备选择合适的驱动程序。格式常为`"厂商,型号"`。 | `compatible = "fsl,imx6ul-adc", "fsl,vf610-adc";`            |
| **`status`**                         | **设备状态**，控制设备是否启用。常见值为 `"okay"`（启用）、`"disabled"`（禁用）、`"fail"`（出错不可用）。 | `status = "okay";`                                           |
| **`#address-cells`**                 | 指定**子节点`reg`属性中“地址”字段**所占的32位整数（cell）的个数 。 | `#address-cells = <1>;`                                      |
| **`#size-cells`**                    | 指定**子节点`reg`属性中“长度”字段**所占的32位整数（cell）的个数 。 | `#size-cells = <1>;`                                         |
| **`reg`**                            | 描述**设备占用的地址空间资源**，通常是寄存器块的起始地址和长度。其格式由父节点的`#address-cells`和`#size-cells`决定 。 | `reg = <0x0200C000 0x4000>;`                                 |
| **`model`**                          | **设备型号描述**，通常是一个字符串，用于标识板卡或SoC的型号 。 | `model = "Freescale i.MX6 UltraLite 14x14 EVK Board";`       |
| **`phandle`**                        | 节点唯一标识符，供其他节点引用。更常用的方式是使用**标签（label）**进行间接引用 。 | `intc: interrupt-controller@00a01000 { ... }`其他节点引用：`interrupt-parent = <&intc>;` |
| **`ranges`**                         | **地址转换表**，用于定义子节点地址空间与父节点地址空间之间的映射关系。值为空表示1:1映射 。 | `ranges = <0x0 0xe0000000 0x00100000>;`                      |
| **`interrupt-parent`**               | 指定该设备节点的**中断控制器**。通常引用一个中断控制器节点 。 | `interrupt-parent = <&gpio1>;`                               |
| **`interrupts`**                     | 描述设备的**中断信号**，其格式（cell的数量和含义）由它所连接的中断控制器的`#interrupt-cells`属性决定 。 | `interrupts = <0 66 4>;`                                     |
| **`pinctrl-0`**, **`pinctrl-names`** | **引脚控制**相关属性，用于指定设备在不同工作状态下的引脚功能配置（如复用为GPIO、UART等）。 | `pinctrl-names = "default";``pinctrl-0 = <&pinctrl_uart1>;`  |
| **`clocks`**, **`clock-names`**      | **时钟**相关属性，指定设备所使用的时钟源 。                  | `clocks = <&clks IMX6UL_CLK_UART1>;`                         |
