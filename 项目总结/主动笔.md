# 主动笔

## 主动笔组成

| 模块       | 描述                                                         |
| ---------- | ------------------------------------------------------------ |
| 笔头/TX1   | TX1下行打码，传导压力；有预压：体验好，但算法复杂；无预压有行程：体验差，可分时做接收； |
| Ring环     | 接收时序：ring环接受来自屏端上行信号；发射时序：下行打码或屏蔽（笔idle）； |
| 打码逻辑   | 实现下行打码时序，并经升压电路输出，具体时序见各个协议文档； |
| 接收模块   | 接受来自屏的上行命令信息：同步；                             |
| 升压电路   | 实现下行高压打码，一般15~40V；                               |
| 压力传感器 | 有效压力范围0\~500g（HLK：350g），实际最大支持5~10kg（考虑跌落）； |
| 蓝牙       | 用于屏笔同步（苹果）；用于双向通信：笔到屏——用于双向息上报，屏到笔——协议切换（外挂、tddi协议不同）、状态信息等命令； |
| 按键       | 1~2个，用于实现橡皮擦、跳出对话框等事件；                    |

## 主动笔协议——分类

主动笔协议约定屏笔交互信号及逻辑，分带上行协议和不带上行协议(不包括苹果协议)。

### 带上行协议

- **典型协议：**USI、HPP3.0-addon、HPP3.0-incell、MPP2.5、LPP。

- **特征：**平时笔只接收上行（uplink），不打下行，有屏靠近且收到正确上行才打下行，上行用于同步和命令传输。

	下图为带上行协议示意图：

![img](https://cdn.jsdelivr.net/gh/mrcq/Image@main/202408281508587.webp)

### 不带上行协议

- **典型协议：**MPP1.51/2.0、HPP2.2。

- **特征：**按固定时序和频点循环打码。

## 主动笔协议——下行编码

笔到屏的数据传输有蓝牙传输和下行编码传输。

### 调频

- 在压力编码段打出不同频率的编码表示不同压力等级，代表协议:MPP1.51/2.0、HPP1.5。

	MPP1.51：23\~18kHZ对应1~256压力等级：

![img](https://cdn.jsdelivr.net/gh/mrcq/Image@main/202408281807528.webp)

### 调幅

- 在固定时序通过打码和不打码表示两种状态。

- 代表协议：HPP2.2

	0:压力编码位无打码

	1:压力编码位有打码
	![image-20240828191302054](https://cdn.jsdelivr.net/gh/mrcq/Image@main/202408281913137.png)

### 调相

- 通过编码之间的相位差表示不同状态，代表协议：USI-180°编码，LPP-90°编码。

- 下图是USI协议的编码，4个编码段表示3个位数据（USI：21段20位编码）

	1:0°

	0:180°
