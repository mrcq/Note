# 编译

## gcc

### gcc常用指令

1. 选项 -o
   用法：gcc test.c -o test
   作用：将test.c预处理、汇编、编译并链接形成可执行文件。

2. 选项 -E

   用法：gcc -E test.c -o test.i
   作用：将test.c预处理输出test.i文件。gcc的-E选项，可以让编译器在预处理后停止，并输出预处理结果。

3. 选项 -S

   用法：gcc -S test.i -o test.s || gcc -S test.c -o test.s
   作用：将预处理输出文件test.i汇编成test.s文件。gcc的-S选项，表示在程序编译期间，在生成汇编代码后，停止，-o输出汇编代码文件。

4. 选项 -c

   用法：gcc test.c -o test
   作用：将test.c预处理、汇编、编译并链接形成可执行文件。这里未指定输出文件，默认输出为a.out（gcc test.c）

5. 选项 -E

   用法：gcc test.c -o test
   作用：将test.c预处理、汇编、编译并链接形成可执行文件。这里未指定输出文件，默认输出为a.out（gcc test.c）
